# Crowns & Ruins

Браузерная средневековая стратегия: строй город, нанимай героев, бей боссов в общем мире, совершай набеги на соседей. Вид сверху под наклоном (изометрия). Клиент — чистый HTML/Canvas без фреймворков, сервер — Node.js + SQLite. Готова к упаковке в APK (Capacitor) для RuStore.

## Запуск

```bash
npm install
npm start            # http://localhost:3000
npm run dev          # с автоперезапуском
```

Первая регистрация создаёт игрока и ставит его город на общую карту. База — `data/game.db` (создаётся сама). `npm run reset-db` стирает мир.

## Что есть

- **Регистрация/вход**, сессии по токену.
- **Город 10×10**: 12 типов зданий (ратуша, ферма, лесопилка, каменоломня, рудник, склад, казармы, таверна, стена, башня, рынок, кузница), уровни, таймеры стройки, лимиты от ратуши, 2 параллельные стройки.
- **Ресурсы**: еда, дерево, камень, железо, золото. Производство в час, вместимость склада, рынок для обмена.
- **Армия**: 6 отрядов, очередь обучения, открываются уровнем казарм.
- **Герои**: 4 класса с навыками, уровни и опыт, ранения.
- **Общий мир 48×48**: все города игроков на одной карте, 6 боссов с общим HP (награда делится по нанесённому урону, добивший — ×1.5), ресурсные точки с откатом, набеги на игроков (щиты новичкам и после атаки).
- **Соц**: чат мира (вести о победах над боссами), рейтинг по силе, отчёты о боях.
- Клиент: тач-управление (перетаскивание, пинч-зум), мобильная вёрстка, предсказание прироста ресурсов.

## Структура

```
server/            API и игровая логика (express + node:sqlite)
  gamedata.js      весь баланс: здания, отряды, герои, боссы, точки
  game.js          ресурсы, стройка, обучение, герои, рынок
  battle.js        симуляция боя
  world.js         генерация общего мира
  index.js         HTTP-маршруты
client/            игра (отдаётся сервером как статика)
  assets/atlas.json  манифест спрайт-листов — сюда кладутся твои PNG
  js/assets.js     загрузка листов + плейсхолдеры
  js/iso.js        изометрическая камера и ввод
  js/city.js       сцена города     js/world.js  сцена мира
  js/ui.js         панели/меню      js/main.js   вход и игровой цикл
docs/PROMPTS.md    промты для генерации графики (один промт = один лист)
docs/BUILD_APK.md  сборка APK и публикация в RuStore
```

## Графика

Сейчас всё рисуется плейсхолдерами. Сгенерируй листы по `docs/PROMPTS.md`, положи PNG в `client/assets/` — игра подхватит их без изменений кода.

## API (кратко)

`POST /api/register|login|logout`, `GET /api/gamedata|state|world|leaderboard|chat`,
`POST /api/build|upgrade|demolish|train|hero/recruit|trade|rename|boss/attack|node/gather|player/attack|chat`.
Все ответы `{ok, ...}` либо `{ok:false, error}`. Авторизация — `Authorization: Bearer <token>`.
