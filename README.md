# Crowns & Ruins

Браузерная средневековая стратегия: строй город, нанимай героев, бей боссов в общем мире, совершай набеги на соседей. Вид сверху под наклоном (изометрия). Клиент — чистый HTML/Canvas без фреймворков, сервер — Node.js + SQLite. Готова к упаковке в APK (Capacitor) для RuStore.

## Запуск

```bash
npm install
npm start            # http://localhost:3000
npm run dev          # с автоперезапуском
```

Первая регистрация создаёт игрока и ставит его город на общую карту. База — `data/game.db` (создаётся сама). `npm run reset-db` стирает мир.

## Что есть

- **Регистрация/вход**, сессии по токену.
- **Город 10×10**: 16 зданий (ратуша, ферма, лесопилка, каменоломня, рудник, склад, казармы, таверна, стена, башня, рынок, кузница, академия, госпиталь, дома, посольство), уровни, таймеры, лимиты от ратуши.
- **Ресурсы**: еда, дерево, камень, железо, золото. Производство в час, вместимость склада, рынок.
- **Армия**: 6 отрядов со скоростью и грузоподъёмностью, очередь обучения. **Госпиталь**: часть потерь — раненые, лечатся за 40% цены.
- **Герои**: 4 класса с навыками, уровни и опыт, ранения, **6 слотов экипировки** (оружие, доспех, шлем, сапоги, кольцо, амулет), 4 редкости, инвентарь, продажа трофеев.
- **Академия**: 5 ветвей исследований (экономика, война, фортификация, логистика, медицина).
- **Походы**: армия реально идёт по карте (время пути от расстояния и самого медленного отряда), видна на карте у всех, можно отозвать. Виды: монстр, босс, сбор ресурсов, набег.
- **Общий мир 48×48**: города всех игроков, 140 монстров 16 видов с уровнями 1–20 (роняют трофеи, возрождаются в новом месте), 6 боссов с общим HP (награда по урону, добивший ×1.5, всем — трофей), ресурсные точки, набеги со щитами.
- **Задания**: цепочка из 22 заданий правителя с наградами.
- **Альянсы**: создание (нужно посольство), вступление, глава, исключение, чат альянса, теги на карте и в рейтинге, союзников нельзя атаковать.
- **Соц**: чат мира с вестями о боссах, рейтинг, отчёты, уведомления о возвращении армии.
- Клиент: тач-управление (перетаскивание, пинч-зум), мобильная вёрстка, предсказание прироста ресурсов.

## Структура

```
server/            API и игровая логика (express + node:sqlite)
  gamedata.js      весь баланс: здания, отряды, герои, боссы, точки
  game.js          ресурсы, стройка, обучение, герои, рынок
  battle.js        симуляция боя
  marches.js       походы: путь, бой на месте, возвращение с добычей
  alliances.js     альянсы
  world.js         генерация общего мира и монстров
  index.js         HTTP-маршруты
client/            игра (отдаётся сервером как статика)
  assets/atlas.json  манифест спрайт-листов — сюда кладутся твои PNG
  js/assets.js     загрузка листов + плейсхолдеры
  js/iso.js        изометрическая камера и ввод
  js/city.js       сцена города     js/world.js  сцена мира
  js/ui.js         панели/меню      js/main.js   вход и игровой цикл
docs/PROMPTS.md    промты для генерации графики (один промт = один лист)
docs/BUILD_APK.md  сборка APK и публикация в RuStore
```

## Графика

Сейчас всё рисуется плейсхолдерами. Сгенерируй листы по `docs/PROMPTS.md`, положи PNG в `client/assets/` — игра подхватит их без изменений кода.

## API (кратко)

`POST /api/register|login|logout`, `GET /api/gamedata|state|world|leaderboard|chat`,
`POST /api/build|upgrade|demolish|train|hero/recruit|trade|rename|chat|march|march/recall|item/equip|item/sell|research|heal|quest/claim|alliance/create|alliance/join|alliance/leave|alliance/kick`,
`GET /api/march/preview|alliances|alliance/:id`.
Все ответы `{ok, ...}` либо `{ok:false, error}`. Авторизация — `Authorization: Bearer <token>`.
